# Gacha More Money · 충전소 · 소환권 · 도감

마리나라 엔진 **가챠 포지 1.8.13**용 개인 확장 **1.1.1**입니다.

| 기능 | 위치 | 서버 패치 |
| --- | --- | --- |
| **충전소** — 가상 결제 상품 10종, 하루 3번 | 상점 왼쪽 목록 맨 아래 [충전소] | 필요 |
| **소환권** — 소환은 에테르 대신 소환권으로 | 소환 화면, 충전소 [소환권 교환] | 필요 |
| **도감** — 적 · 캐릭터 · 의상 · 배경 · 전투 배경 · CG · 배너 · 인연 배경 그림 | 홈 로비 [✥ 배치] 아래 [도감] (책 아이콘) | 적 · 전투 배경만 필요 |

진짜 돈은 나가지 않습니다. 충전 상품 버튼을 한 번 누르면 "결제할까요?"로 바뀌고, 한 번 더 누르면 지갑에 들어갑니다.

## 소환권

패치를 적용하면 소환에 에테르가 들지 않고 소환권이 듭니다.

| 소환권 | 쓰는 배너 | 에테르로 교환 |
| --- | --- | --- |
| **성휘** (상시 소환권) | 상시 배너 (캐릭터 · 무기) | 1장 = 에테르 160, 10장 = 1,600 |
| **월휘** (한정 소환권) | 한정(픽업) 배너 (캐릭터 · 무기) | 1장 = 에테르 160, 10장 = 1,600 |

- 1회 소환에 1장, 10회 소환에 10장이 듭니다. 교환 비율이 예전 소환 비용과 같아서 에테르 가치는 그대로입니다.
- 교환은 횟수 제한이 없습니다. 충전소 [소환권 교환]이나 소환 화면의 [+1장] · [+10장] 버튼으로 바꿉니다.
- 소환 화면의 가격 표시가 소환권으로 바뀌고, 소환권이 모자라면 소환 버튼이 꺼집니다.
- 소환권은 세계(런)마다 지갑에 따로 쌓입니다.

## 충전 상품

세 상품을 합쳐 **하루 3번**까지 살 수 있습니다. 횟수는 세계마다 따로 세고, 마리나라 서버 컴퓨터의 날짜가 바뀌면 다시 3번이 됩니다.

| 상품 | 받는 것 | 표시 가격 |
| --- | --- | --- |
| 첫걸음 꾸러미 | 에테르 1,600 · 자금 50,000 · 월휘 1장 | ₩4,400 |
| 월휘 꾸러미 | 월휘 10장 | ₩49,000 |
| 성휘 꾸러미 | 성휘 10장 | ₩29,000 |
| 에테르 한 줌 | 에테르 1,600 | ₩33,000 |
| 에테르 상자 | 에테르 4,800 | ₩99,000 |
| 에테르 보물고 | 에테르 9,600 | ₩199,000 |
| 자금 자루 | 자금 100,000 | ₩11,000 |
| 자금 금괴 | 자금 300,000 | ₩29,000 |
| 활력 드링크 | 활력 +60 (최대치를 넘어 채워짐) | ₩5,500 |
| 반짝이 주머니 | 반짝이 300 | ₩8,800 |

## 왜 서버 패치가 필요한가요?

에테르 · 자금은 가챠 포지의 서버 저장 데이터에 있고, 브라우저 확장이 그 값을 바꿀 수 있는 통로가 게임에 없습니다. 마리나라의 서버 확장도 격리돼 있어 게임 데이터에 닿지 못합니다. 그래서 가챠 포지의 `server.mjs`에 아래 요청 세 개를 덧붙이는 패치를 함께 넣었습니다.

- `POST /api/gacha-forge/more-money/status` — 오늘 남은 충전 횟수
- `POST /api/gacha-forge/more-money/topup` — 충전 (하루 3번 제한은 서버에서 셉니다)
- `POST /api/gacha-forge/more-money/exchange` — 에테르로 소환권 사기
- `POST /api/gacha-forge/more-money/codex` — 도감용 적 그림 · 전투 배경 목록
- 그리고 소환 처리에서 에테르를 빼던 부분을 소환권을 빼도록 바꿉니다(원래 코드는 패치 안에 그대로 보관해 `--restore`로 되돌립니다).

마리나라는 설치된 패키지 파일의 해시를 검사합니다. 패치 스크립트는 파일을 고친 뒤 설치 기록(`capability-packages/installed.json`)의 해시도 같이 고칩니다. 처음 패치할 때 원본을 `server.mjs.gmm-backup`으로 남깁니다.

## 설치

1. 마리나라 **애드온 → 개인 확장**에서 이 저장소(또는 `manifest.json`과 `extension.js`)를 추가하고 켭니다.
2. **마리나라를 끕니다.** 켜 둔 채로 패치하면 마리나라가 설치 기록을 옛 해시로 덮어쓸 수 있습니다.
3. 마리나라 엔진 폴더에서 패치를 실행합니다(Node.js 필요, 마리나라를 돌리는 그 Node면 됩니다).
   ```
   node 경로/gacha-more-money/patch/apply-patch.mjs
   ```
   data 폴더를 못 찾으면 직접 적어 주세요.
   ```
   node apply-patch.mjs C:\Marinara-Engine\packages\server\data
   ```
   `DATA_DIR` 환경 변수, `./packages/server/data`, `./data`, 현재 폴더 순서로 찾습니다.
4. 마리나라를 다시 켭니다. 상점 [충전소] 옆에 "오늘 3/3"이 보이면 됩니다. "패치 필요"가 보이면 3단계를 다시 확인하세요.

- 다시 실행해도 패치는 한 번만 들어갑니다.
- **가챠 포지를 업데이트하면 패치가 사라집니다.** 업데이트한 뒤 3~4단계를 다시 하세요. 게임 코드가 많이 바뀌어 패치할 자리를 못 찾으면 스크립트가 아무것도 고치지 않고 멈춥니다.
- 패치 제거: `node apply-patch.mjs --restore` (마리나라를 끈 상태에서)

## 도감

- 탭: 적 · 캐릭터 · 의상 · 배경 · 전투 배경 · CG · 배너 · 인연 배경. 게임에서 이미 그려진 그림만 모입니다.
- 그림을 누르면 크게 보고, ◀ ▶(또는 키보드 방향키)로 넘깁니다. Esc로 닫습니다.
- 말랑 UI가 켜져 있으면 그 색을 따르고, 버튼도 [✥ 배치] 바로 아래에 섭니다. 말랑 UI 없이도 홈 화면 같은 자리에 버튼이 나옵니다.
- 서버 패치가 없으면 적 · 전투 배경 탭에 "패치"라고 표시되고, 나머지 탭은 그대로 볼 수 있습니다.

## 바뀐 점

### 1.1.1 — 확장만 바뀜 (패치는 다시 실행하지 않아도 됩니다)
- 소환권 이름을 줄였습니다: 별의 서약 → **성휘**(星輝, 상시), 월식의 서약 → **월휘**(月輝, 한정).
- 상품 · 소환권 아이콘을 글자 기호 대신 직접 그린 그림(소환권 티켓, 에테르 보석, 동전 더미, 금괴, 활력 병, 반짝이, 선물 상자)으로 바꿨습니다.

### 1.1.0 — 패치를 다시 실행해야 합니다
- 소환권 「성휘」(상시) · 「월휘」(한정)을 추가하고, 소환이 에테르 대신 소환권을 씁니다.
- 충전소 상품을 3종에서 10종으로 늘리고, 에테르 → 소환권 교환을 넣었습니다. 소환 화면에서도 바로 교환할 수 있습니다.
- 1.0.x 패치를 적용해 두었다면, 마리나라를 끄고 새 `apply-patch.mjs`를 다시 실행하세요. 옛 패치를 걷어내고 새 패치를 넣습니다.
